# Test Functions

>[!DEFINITION] Definition: Test Functions
>
>Let $\Omega$ be an [open](../../Topology/Topological%20Spaces/Open%20Sets.md) [subset](../../Set%20Theory/Subsets.md) of the [Euclidean space](../Real%20Analysis/Euclidean%20Space/Euclidean%20Space.md) $\mathbb{R}^n$.
>
>A **test function** on $\Omega$ is a [real scalar field](../Real%20Analysis/Real-Valued%20Functions%20of%20Multiple%20Real%20Variables/Real-Valued%20Functions%20of%20Multiple%20Real%20Variables.md) $\phi: \Omega \to \mathbb{R}$ which is [infinitely continuously partially differentiable](../Real%20Analysis/Real-Valued%20Functions%20of%20Multiple%20Real%20Variables/Differentiation/Partial%20Differentiability%20(Real%20Scalar%20Fields).md) and has [compact support](../Functional%20Analysis/Compact%20Support.md).
>
>>[!NOTATION]
>>
>>$$\mathcal{D}(\Omega)$$
>>
>

>[!THEOREM] Theorem: Test Function Space
>
>Let $\Omega$ be an [open](../../Topology/Topological%20Spaces/Open%20Sets.md) [subset](../../Set%20Theory/Subsets.md) of the [Euclidean space](../Real%20Analysis/Euclidean%20Space/Euclidean%20Space.md) $\mathbb{R}^n$.
>
>The [set](../../Set%20Theory/Sets.md) $\mathcal{D}(\Omega)$ of all [test functions](./Test%20Functions.md) on $\Omega$ forms a [vector space](../../Algebra/Vector%20Spaces/Vector%20Spaces.md) with the [real numbers](../../Algebra/Fields/The%20Real%20Numbers/The%20Real%20Numbers.md) and point-wise [addition](../Real%20Analysis/Real-Valued%20Functions.md) and [multiplication](../Real%20Analysis/Real-Valued%20Functions.md):
>
>$$(\mathcal{D}(\Omega), \mathbb{R}, +, \cdot)$$
