# Partitions

>[!DEFINITION] Definition: Partition
>
>A **partition** of a [set](./Sets.md) $S$ is a [collection](./Collections.md) $\mathcal{P}$ of [subsets](./Sets.md#Subsets) of $S$ with the following properties:
>- non-emptiness: $\mathcal{P} \ne \varnothing$;
>- pairwise disjointness: $A \cap B = \varnothing$ for all $A, B \in \mathcal{P}$;
>- covering: $S = \bigcup \mathcal{P}$.
>
