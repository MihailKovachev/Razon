# Heaviside Step Function

>[!DEFINITION] Definition: Heaviside Step Function
>
>The **Heaviside step function** is the [real function](./Real%20Functions.md) $H: \mathbb{R} \to \mathbb{R}$ defined as follows:
>
>$$H(x) = \begin{cases}0, & x \lt 0 \\ 1, & x \ge 1\end{cases}$$
>
>>[!WARNING] Warning: Conventions for $H(0)$
>>
>>Some conventions define $H(0) = 0$.
>>
>
