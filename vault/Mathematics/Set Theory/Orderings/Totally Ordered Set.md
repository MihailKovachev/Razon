# Totally Ordered Set

>[!DEFINITION] Definition: Total Order
>
>A **total order** on a [set](../Sets.md) $S$ is a [partial order](./Partially%20Ordered%20Set.md) $\le$ under which all elements are [comparable](./Partially%20Ordered%20Set.md):
>
>$$\forall a, b \in S: a \le b \text{ or } b \le a$$
>
