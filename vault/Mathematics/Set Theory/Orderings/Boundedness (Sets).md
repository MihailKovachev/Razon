# Boundedness (Sets)

>[!DEFINITION] Definition: Boundedness
>
>Let $(X, \le)$ be a [partially ordered set](./Partially%20Ordered%20Set.md) and let $S$ be a [subset](../Subsets.md) of $X$.
>
>>[!DEFINITION] Definition: Lower Bound
>>
>>A **lower bound** of $S$ is any $l \in X$ such that $l \le x$ for all $x \in S$.
>>
>>>[!DEFINITION] Definition: Boundedness Below
>>>
>>>We say that $S$ is **bounded below** if it has a [lower bound](./Boundedness%20(Sets).md).
>>>
>>>
>>
>
>>[!DEFINITION] Definition: Upper Bound
>>
>>An **upper bound** of $S$ is any $u \in X$ such that $x \le u$ for all $x \in S$.
>>
>>>[!DEFINITION] Definition: Boundedness Above
>>>
>>>We say that $S$ is **bounded above** if it has an [upper bound](./Boundedness%20(Sets).md).
>>>
>>>
>>
>
>We say that $S$ is **bounded** if it is both [bounded below](./Boundedness%20(Sets).md) and [bounded above](./Boundedness%20(Sets).md).
>
