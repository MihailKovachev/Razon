# Categories

>[!DEFINITION] Definition: Category
>
>A **category** $\mathcal{C}$ consists of the following:
>- a [class](TODO) $\mathop{\operatorname{ob}}(\mathcal{C})$ whose elements are called **objects**;
>- a [class](TODO) $\hom(\mathcal{C})$ whose elements are called **morphisms** / **arrows**, where each [morphism](./Categories.md) $f$ has a **source object** $a \in \mathop{\operatorname{ob}}(\mathcal{C})$ and a **target object** $b \mathop{\operatorname{ob}}(\mathcal{C})$. We say that $f$ is a **morphism from** $a$ **to** $b$.
