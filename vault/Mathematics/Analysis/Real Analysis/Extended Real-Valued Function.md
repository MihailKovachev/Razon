# Extended Real-Valued Function

>[!DEFINITION] Definition: Extended Real-Valued Function
>
>An **extended real-valued function** is a [function](../Functions/Functions.md) whose [codomain](../Functions/Functions.md) is a [subspace](../../Topology/Topological%20Subspaces.md) of the [extended real number line](./Extended%20Real%20Number%20Line.md).
>
