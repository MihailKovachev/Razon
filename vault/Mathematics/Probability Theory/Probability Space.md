# Probability Space

>[!DEFINITION] Definition: Probability Space
>
>A **probability space** is a [measure space](../Measure%20Theory/Measure%20Space.md) $(X, \Sigma, \mu)$ with a [probability measure](./Probability%20Measure.md) $\mu$.
>
>>[!DEFINITION] Definition: Sample Space
>>
>>We call $X$ the **sample space**.
>>
>>>[!NOTATION]
>>>
>>>The [sample space](./Probability%20Space.md) is typically denoted by $\Omega$.
>>>
>>
>
>>[!DEFINITION] Definition: Event Space
>>
>>We call $\Sigma$ the **event space**.
>>
>>>[!NOTATION]
>>>
>>>The [event space](./Probability%20Space.md) is typically denoted by $\mathcal{F}$.
>>>
>>
>
