# Affine Subspaces

>[!DEFINITION] Definition: Affine Subspace
>
>Let $(V, F, +, \cdot)$ be a [vector space](./Vector%20Spaces.md).
>
>A [subset](../../Set%20Theory/Subsets.md) $A \subseteq V$ is an **affine subspace** of $V$ if there exists some [vector](./Vector%20Spaces.md) $\boldsymbol{v} \in V$ and some [linear subspace](./Linear%20Subspaces.md) $W \le V$ such that $A$ can be expressed as follows:
>
>$$A = \{ \boldsymbol{v} + \boldsymbol{w} \mid \boldsymbol{w} \in W\}$$
