# Common Gate Amplifier

## Small-Signal Model with Resistive Source and Load

$$A_V = \frac{g_{\text{m}}}{g_{\text{DS}} + g_{\text{load}}}$$

$$A_I = -1$$

$$r_{\text{in}} = r_{\text{m}}$$

$$r_{\text{out}} = r_{\text{DS}}\left(1 + \frac{r_{\text{source}}}{r_{\text{m}}}\right)$$
