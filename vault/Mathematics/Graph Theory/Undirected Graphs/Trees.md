# Trees

>[!DEFINITION] Definition: Tree
>
>A **tree** is a [connected](./Undirected%20Graphs.md) [acyclic](./Cyclicity%20(Undirected%20Graphs).md) [undirected graph](./Undirected%20Graphs.md).
>

>[!DEFINITION] Definition: Spanning Tree
>
>A **spanning tree** of an [undirected graph](./Undirected%20Graphs.md) $G = (V, E)$ is a [subgraph](./Undirected%20Graphs.md) $T = (V', E')$ of $G$ which is a [tree](./Trees.md) such that $V' = V$.
>
