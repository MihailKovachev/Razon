# Linearity (Dynamical Systems)

>[!DEFINITION] Definition: Linear Dynamical System
>
>A [dynamical system](./Dynamical%20Systems.md) $(\mathbb{T}, \mathbb{W}, \mathfrak{B})$ is **linear** if $\mathbb{W}$ is a [vector space](../Algebra/Vector%20Spaces/Vector%20Spaces.md) and $\mathfrak{B}$ is a [linear subspace](../Algebra/Vector%20Spaces/Linear%20Subspaces.md) of the [canonical function space](../Analysis/Functions/Canonical%20Function%20Space.md) $\mathbb{W}^{\mathbb{T}}$.
>

>[!DEFINITION] Definition: Linear Dynamical System with Latent Variables
>
>A [dynamical system with latent variables](./Dynamical%20Systems.md) $(\mathbb{T}, \mathbb{W}, \mathbb{L}, \mathfrak{B}_{\text{full}})$ is **linear** if $\mathbb{W}$ and $\mathbb{L}$ are [vector spaces](../Algebra/Vector%20Spaces/Vector%20Spaces.md) over the same [field](../Algebra/Fields/Fields.md) and $\mathfrak{B}_{\text{full}}$ is a [linear subspace](../Algebra/Vector%20Spaces/Linear%20Subspaces.md) of the [canonical function space](../Analysis/Functions/Canonical%20Function%20Space.md) $(\mathbb{W} \times \mathbb{L})^{\mathbb{T}}$.
>
