# Real Random Vector

>[!DEFINITION] Definition: Real Random Variable
>
>Let $(\Omega, \mathcal{F}, \Pr)$ be a [probability space](../Probability%20Space.md).
>
>A **real random variable** is a [real vector-valued function](../../Analysis/Real%20Analysis/Real%20Vector-Valued%20Functions.md) $X: \Omega \to \mathbb{R}^n$ which is [measurable](../../Measure%20Theory/Measurable%20Functions.md) with respect to $\mathcal{F}$ and the [Borel σ-algebra](../../Measure%20Theory/Borel%20σ-Algebra.md) of the [Euclidean space](../../Analysis/Real%20Analysis/Euclidean%20Space/Euclidean%20Space.md) $\mathbb{R}^n$.
>
