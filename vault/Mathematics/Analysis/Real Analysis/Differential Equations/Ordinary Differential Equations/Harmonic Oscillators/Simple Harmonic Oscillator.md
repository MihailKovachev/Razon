# Simple Harmonic Oscillators

>[!DEFINITION] Definition: simple harmonic oscillator
>
>A **simple harmonic oscillator** is a [second-order](../Real%20Ordinary%20Differential%20Equations.md) [linear](../Linear%20Ordinary%20Differential%20Equations.md) [ordinary differential equation](../Real%20Ordinary%20Differential%20Equations.md) of the form
>
>$$\ddot{x} + \omega_0^2 x = 0 \qquad$$
>
>with $\omega_0 \in \mathbb{R}_{\gt 0}$.
>
>>[!DEFINITION] Definition: Natural Angular Frequency
>>
>>We call $\omega_0$ the **natural angular frequency**.
>>
>

>[!THEOREM] Theorem: Solutions of the Simple Harmonic Oscillator (Mixed Form)
>
>The [solutions](../Real%20Ordinary%20Differential%20Equations.md) of the [simple harmonic oscillator](./Simple%20Harmonic%20Oscillator.md)
>
>$$\ddot{x} + \omega_0^2 x = 0 \qquad$$
>
>on $\mathbb{R}$ can be expressed using [sine](../../../Real%20Functions/Real%20Trigonometric%20Functions/Real%20Sine%20Function.md) and [cosine](../../../Real%20Functions/Real%20Trigonometric%20Functions/Real%20Cosine%20Function.md) as
>
>$$x(t) = C_1\cos(\omega_0 t) + C_2 \sin (\omega_0 t)$$
>
>with $C_1, C_2 \in \mathbb{R}$.

>[!THEOREM] Theorem: Solutions of the Simple Harmonic Oscillator (Sine Form)
>
>The [solutions](../Real%20Ordinary%20Differential%20Equations.md) of the [simple harmonic oscillator](./Simple%20Harmonic%20Oscillator.md)
>
>$$\ddot{x} + \omega_0^2 x = 0 \qquad$$
>
>on $\mathbb{R}$ can be expressed using [sine](../../../Real%20Functions/Real%20Trigonometric%20Functions/Real%20Sine%20Function.md) as
>
>$$x(t) = A \sin (\omega_0 t + \phi)$$
>
>with $A \in \mathbb{R}_{\ge 0}$ and $\phi \in [0, \uppi)$.
>
