# Strictly Linear Resistive One-Ports

>[!THEOREM] Theorem: Strictly Linear Resistive One-Ports in Series
>
>If $n$ [strictly linear resistive one-ports](./Strictly%20Linear%20Resistive%20One-Ports.md) with [resistances](./Strictly%20Linear%20Resistive%20One-Ports.md) $R_1, \dotsc, R_n$ and [conductances](./Strictly%20Linear%20Resistive%20One-Ports.md) $G_1, \dotsc, G_n$, respectively, are connected in [series](./One-Port%20Series%20Circuits.md), then they are equivalent to a single [strictly linear resistive one-ports](./Strictly%20Linear%20Resistive%20One-Ports.md) whose [resistance](./Strictly%20Linear%20Resistive%20One-Ports.md) $R$ and [conductance](./Strictly%20Linear%20Resistive%20One-Ports.md) $G$ are given as follows:
>
>$$R = \sum_{i=1}^n R_i = R_1 + R_2 + \cdots + R_n$$
>
>$$\frac{1}{G} = \sum_{i=1}^n \frac{1}{G_i} = \frac{1}{G_1} + \frac{1}{G_2} + \cdots + \frac{1}{G_n}$$

>$$G = \sum_{i=1}^n G_i = G_1 + G_2 + \cdots + G_n$$
