# First-Countable Topological Space

>[!DEFINITION] Definition: First-Countable Topological Space
>
>A [topological space](../Topological%20Spaces/Topological%20Space.md) $X$ is **first-countable** if there exists a [countable](../../Set%20Theory/Cardinality.md) [neighborhood basis](./Neighborhood%20Basis.md) for it at each $p \in X$.
>
