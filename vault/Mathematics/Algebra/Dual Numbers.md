# The Dual Numbers

>[!DEFINITION] Definition: Dual Number
>
>A **dual number** is an expression of the form
>
>$$
>a + b\varepsilon,
>$$
>
>where $a, b \in \mathbb{R}$ are [real numbers](./Fields/The%20Real%20Numbers/The%20Real%20Numbers.md) and $\varepsilon$ is defined such that
>
>$$
>\varepsilon^2 = 0 \text{ and } \varepsilon \ne 0.
>$$
>
>>[!NOTATION] Notation
>>
>>The set of all [dual numbers](./Dual%20Numbers.md) is usually denoted by $\mathbb{R}[\varepsilon]$.
>>
>
