# Vector Space Endomorphisms

>[!DEFINITION] Definition: Endomorphism
>
>An **endomorphism** is a [linear transformation](../Linearity%20(Functions).md) from a [vector space](../../../../Algebra/Vector%20Spaces/Vector%20Spaces.md) to itself:
>
>$$f: V \to V$$
>
