# Open Map

>[!DEFINITION] Definition: Open Map
>
>Let $X$ and $Y$ be [topological spaces](../Topology/Topological%20Spaces/Topological%20Space.md).
>
>A [function](./Functions/Functions.md) $f: X \to Y$ is an **open map** if the [image](./Functions/Functions.md) $f(U)$ of each [open set](../Topology/Topological%20Spaces/Open%20Sets.md) $U \subseteq X$ is an [open set](../Topology/Topological%20Spaces/Open%20Sets.md) of $Y$.
>
