# Yat Reflex (Bulgarian)

**Variable ya** (**променливо я**) is a phenomenon where the [Old Church Slavonic](TODO) letter ⟨Ѣ⟩ in a word root evolved into the letter ⟨я⟩ in some inflections and derivatives of a given word and into the letter ⟨е⟩ in others. 

When a word root is subject to the [variable ya](./Yat%20Reflex%20(Bulgarian).md) phenomenon, we can determine if a given inflection or derivative is spelled with ⟨я⟩ or ⟨е⟩ using the following rules. Specifically, the word root is spelled with ⟨я⟩ only if all of the following conditions are simultaneously met:

- The syllable with the [variable ya](./Yat%20Reflex%20(Bulgarian).md) is [stressed](./Phonology%20(Bulgarian).md).
- If there is a subsequent syllable, it does not containg the letters any of the letters ⟨е⟩, ⟨и⟩, ⟨ю⟩, ⟨я⟩ and ⟨ь⟩.
- From the [variable ya](./Yat%20Reflex%20(Bulgarian).md) until either the next vowel or the end of the word (inclusive), there is none of the letters ⟨ж⟩, ⟨ш⟩, ⟨ч⟩, ⟨дж⟩ and ⟨й⟩.

Even if one of these is not satisfied, the root is spelled with ⟨е⟩.

These rules allows to determine the spelling of a word if we already know that its root is subject to the [variable ya](./Yat%20Reflex%20(Bulgarian).md). However, without prior etymological knowledge it is not possible to determine if the root is subject to [variable ya](./Yat%20Reflex%20(Bulgarian).md) in the first place.
