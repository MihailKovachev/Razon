# Real Vector Fields

>[!DEFINITION] Definition: Real Vector Field
>
>A **real vector field** is a [real vector function](../Real-Valued%20Functions.md#Real%20Vector%20Functions) of the form $f: \mathcal{D} \subseteq \mathbb{R}^n \to \mathbb{R}^n$.
>
>>[!NOTATION]
>>
>>Vector fields are sometimes denoted with bold symbols - $\boldsymbol{u}, \boldsymbol{v}, \boldsymbol{F}, \boldsymbol{E}$, etc.
>>
>
