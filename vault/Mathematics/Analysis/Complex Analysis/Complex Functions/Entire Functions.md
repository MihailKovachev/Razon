# Entire Functions

>[!DEFINITION] Definition: Entire Function
>
>An **entire function** is any [complex function](./Complex%20Functions.md) $f: \mathbb{C} \to \mathbb{C}$ which is [holomorphic](./Holomorphic%20Functions.md) on $\mathbb{C}$.
>
