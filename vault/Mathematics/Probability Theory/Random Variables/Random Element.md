# Random Element

>[!DEFINITION] Definition: Random Variable
>
>Let $(\Omega, \mathcal{F}, \Pr)$ be a [probability space](../Probability%20Space.md) and let $(V, \Sigma_V)$ be a [measurable space](../../Measure%20Theory/Measurable%20Space.md).
>
>A **random element** is a [function](../../Analysis/Functions/Functions.md) $X: \Omega \to V$ which is $(\mathcal{F}, \Sigma_V)$[-measurable](../../Measure%20Theory/Measurable%20Functions.md).
>
