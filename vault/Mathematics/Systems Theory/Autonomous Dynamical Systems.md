# Autonomous Dynamical Systems

>[!DEFINITION] Definition: Autonomous Dynamical System
>
>A [dynamical system](./Dynamical%20Systems.md) $(\mathbb{T}, \mathbb{W}, \mathfrak{B})$ is **autonomous** if there exists some $t_0 \in \mathbb{T}$ such that for all [trajectories](./Dynamical%20Systems.md) $w_1, w_2 \in \mathfrak{B}$, if $w_1(t) = w_2(t)$ for each $t \le t_0$, then there exists some [null set](../Measure%20Theory/Null%20Sets.md) $N \subseteq \mathbb{T}$ of the [Lebesgue Measure](../Measure%20Theory/Lebesgue%20Measure.md) with $w_1(t) = w_2(t)$ for all $t \in \mathbb{T} \setminus N$.
