# Cuboids

 >[!DEFINITION] Definition: Cuboids
 >
 >Let $n \in \mathbb{N}$ and let $X$ be a [Cartesian product](../Cartesian%20Product.md) $X = X_1 \times \cdots \times X_n$ of [totally ordered sets](./Totally%20Ordered%20Set.md) $X_1, \dotsc, X_n$.
 >
 >A **cuboid** is a [subset](../Subsets.md) of $X$ which can be expressed as the [Cartesian product](../Cartesian%20Product.md) of [intervals](./Interval.md) of $X_1, \dotsc, X_n$.
 >
 >>[!DEFINITION] Definition: Open Cuboid
 >>
 >>An **open cuboid** is a [cuboid](./Cuboids.md) which can be expressed as the [Cartesian product](../Cartesian%20Product.md) of only [open intervals](./Interval.md) of $X_1, \dotsc, X_n$.
 >>
 >>$$(a_1,b_1) \times \cdots \times (a_n, b_n)$$
 >>
 >
 >>[!DEFINITION] Definition: Closed Cuboid
 >>
 >>A **closed cuboid** is a [cuboid](./Cuboids.md) which can be expressed as the [Cartesian product](../Cartesian%20Product.md) of only [closed intervals](./Interval.md) of $X_1, \dotsc, X_n$.
 >>
 >>$$[a_1,b_1] \times \cdots \times [a_n, b_n]$$
 >>
 >
