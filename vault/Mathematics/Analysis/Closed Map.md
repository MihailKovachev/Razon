# Closed Map

>[!DEFINITION] Definition: Closed Map
>
>Let $X$ and $Y$ be [topological spaces](../Topology/Topological%20Spaces/Topological%20Space.md).
>
>A [function](./Functions/Functions.md) $f: X \to Y$ is a **closed map** if the [image](./Functions/Functions.md) $f(C)$ of each [closed set](../Topology/Topological%20Spaces/Closed%20Sets.md) $C \subseteq X$ is a [closed set](../Topology/Topological%20Spaces/Closed%20Sets.md) of $Y$.
>
