# XNOR Gate


>[!DEFINITION] Definition: XNOR Gate
>
>An **XNOR gate** is a [logic gate](./Logic%20Gates.md) which computes the [negation](../../../Mathematics/Algebra/Boolean%20Algebra/Boolean%20Functions.md#Fundamental%20Connectives) of an [exclusive disjunction](../../../Mathematics/Algebra/Boolean%20Algebra/Boolean%20Functions.md#Fundamental%20Connectives):
>
>$$\mathop{\operatorname{NOT}} \circ \mathop{\operatorname{XOR}}$$
>
>>[!NOTATION]
>>
>>The following symbols are used for NOR gates:
>>
>>![XNOR Gate Symbol](../res/XNOR%20Gate%20Symbol.svg)
>>
>
