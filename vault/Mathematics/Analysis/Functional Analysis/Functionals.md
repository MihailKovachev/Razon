# Functionals

>[!DEFINITION] Definition: Functional
>
>Let $(V, F, +, \cdot)$ be a [vector space](../../Algebra/Vector%20Spaces/Vector%20Spaces.md).
>
>A **functional** is a [function](../Functions/Functions.md) of the following form:
>
>$$f: V \to F$$
>
