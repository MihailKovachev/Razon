# Real-Valued Functions of Multiple Real Variables

>[!DEFINITION] Definition: Real-Valued Function of Multiple Real Variables
>
>A **real-valued function of $n$ real variables** is a [real-valued function](../Real-Valued%20Functions.md) whose [domain](../../Functions/Functions.md) is a [subset](../../../Set%20Theory/Subsets.md) of the [real vector space](../../../Algebra/Linear%20Algebra/Real%20Vectors/Real%20Vectors.md) $\mathbb{R}^n$:
>
>$$f: \mathcal{D} \subseteq \mathbb{R}^n \to \mathbb{R}$$
>
>>[!EXAMPLE]-
>>
>>The [function](../../Functions/Functions.md) $f: \mathbb{R}^n \to \mathbb{R}$ defined as
>>
>>$$f(x_1, \dotsc, x_n) \overset{\text{def}}{=} \sqrt{x_1^2 + \cdots x_n^2}$$
>>
>>is a [real scalar field](./Real-Valued%20Functions%20of%20Multiple%20Real%20Variables.md).
>>
>
>>[!EXAMPLE]-
>>
>>Let $\Omega \subset \mathbb{R}^n$ be an [open ball](../Euclidean%20Space/Euclidean%20Space.md) centered at $\mathbf{p} \in \mathbb{R}^n$ and with radius $r \gt 0$ and let $A \in \mathbb{R}^{n \times n}$ be any [real matrix](../../../Algebra/Matrices/Real%20Matrices/Real%20Matrices.md). The [function](../../Functions/Functions.md) $f: \Omega \to \mathbb{R}$ defined as
>>
>>$$f(\boldsymbol{x}) \overset{\text{def}}{=} \boldsymbol{x}^{\mathsf{T}}A\boldsymbol{x}$$
>>
>>is a [real scalar field](./Real-Valued%20Functions%20of%20Multiple%20Real%20Variables.md).
>>
>
