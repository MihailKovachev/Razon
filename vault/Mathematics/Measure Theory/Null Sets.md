# Null Sets

>[!DEFINITION] Definition: Null Set
>
>Let $(X, \Sigma, \mu)$ be a [measure space](./Measures.md).
>
>We say that a [measurable set](./σ-Algebras.md) $N \in \Sigma$ is a **null set** if its [measure](./Measures.md) is zero:
>
>$$\mu(N) = 0$$
>
