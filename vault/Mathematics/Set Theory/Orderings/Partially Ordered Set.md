# Partial Orders

>[!DEFINITION] Definition: Partial Order
>
>A **partial order** on a [set](../Sets.md) $S$ is a [relation](../Relations.md) $R \subseteq S \times S$ which is [reflexive](../Relations.md), [transitive](../Relations.md) and [asymmetric](../Relations.md).
>
>>[!NOTATION]
>>
>>Partial orders are usually denoted by $\le$ instead of $R$.
>>
>
>>[!DEFINITION] Definition: Comparability
>>
>>Let $a, b \in S$.
>>
>>We say that $a$ and $b$ are **comparable** under $\le$ if $a \le b$ or $b \le a$.
>>
>

>[!DEFINITION] Definition: Partially Ordered Set
>
>A **partially ordered set** $(S, \le)$ is a [set](../Sets.md) $S$ equipped with a [partial order](./Partially%20Ordered%20Set.md) $\le$.
>

>[!DEFINITION] Definition: Strict Partial Order
>
>Let $A$ be a [set](../Sets.md).
>
>A **strict partial order** of $A$ is a [relation](../Relations.md) $R \subseteq A \times A$ which is [irreflexive](../Relations.md), [transitive](../Relations.md) and [antisymmetric](../Relations.md).
>
>>[!NOTATION]
>>
>>Partial orders are usually denoted by $\lt$ instead of $R$.
>>
>
