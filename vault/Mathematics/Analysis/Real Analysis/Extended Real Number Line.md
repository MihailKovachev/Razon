# Extended Real Number Line

>[!DEFINITION] Definition: Extended Real Number Line
>
>The **extended real number line** is the [topological space](../../Topology/Topological%20Spaces/Topological%20Space.md) $\overline{\mathbb{R}}$ consisting of the [extended real numbers](../../Algebra/Extended%20Real%20Numbers.md) and the [order topology](../../Topology/Order%20Topology.md) induced by extending the standard [total order](../../Set%20Theory/Orderings/Totally%20Ordered%20Set.md) of the [real numbers](../../Algebra/Fields/The%20Real%20Numbers/The%20Real%20Numbers.md) as follows:
>
>    - $-\infty \lt x$ for all $x \in \mathbb{R}$
>    - $x \lt +\infty$ for all $x \in \mathbb{R}$
>    - $-\infty \lt + \infty$
>
