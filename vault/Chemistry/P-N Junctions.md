# P-N Junctions

A **P-N junction** is a physical region within a material which forms when a [P-type dopant](./P-Type%20Semiconductors.md) is introduced into an [N-type semiconductor](./N-Type%20Semiconductors.md) or when an [N-type dopant](./N-Type%20Semiconductors.md) is introduced into a [P-type semiconductor](./P-Type%20Semiconductors.md).
