# Boundedness (Functions)

>[!DEFINITION] Definition: Boundedness (Functions)
>
>Let $X$ be a [set](../../Set%20Theory/Sets.md), let $S$ be a [subset](../../Set%20Theory/Subsets.md) of $X$ and let $Y$ be a [totally ordered set](../../Set%20Theory/Orderings/Totally%20Ordered%20Set.md). Let $f: X \to Y$ be a [function](../Functions/Functions.md).
>
>>[!DEFINITION] Definition: Upper Bound
>>
>>An **upper bound** of $f$ on $S$ is any $u \in Y$ such that $f(x) \le u$ for all $x \in S$.
>>
>>>[!DEFINITION] Definition: Boundedness Above
>>>
>>>We call $f$ **bounded above** on $S$ if it has an [upper bound](./Boundedness%20(Functions).md) on $S$.
>>>
>>
>
>>[!DEFINITION] Definition: Lower Bound
>>
>>A **lower bound** of $f$ on $S$ is any $l \in Y$ such that $l \le f(x)$ for all $x \in S$.
>>
>>>[!DEFINITION] Definition: Boundedness Below
>>>
>>>We call $f$ **bounded below** on $S$ if it has a [lower bound](./Boundedness%20(Functions).md) on $S$.
>>>
>>
>
>We call $f$ **bounded** on $S$ if it is both [bounded below](./Boundedness%20(Functions).md) and [bounded above](./Boundedness%20(Functions).md) on $S$.
>
>
>>[!NOTE]
>>
>>If $S = X$, then we can omit the "on $S$" part.
>>
>
