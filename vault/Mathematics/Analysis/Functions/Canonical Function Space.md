# Canonical Function Space

>[!THEOREM] Theorem: Canonical Function Space
>
>Let $\mathcal{D}$ be a [set](../../Set%20Theory/Sets.md) and let $(V, F)$ be a [vector space](../../Algebra/Vector%20Spaces/Vector%20Spaces.md).
>
>The [set](../../Set%20Theory/Sets.md) of all [functions](./Functions.md) $f: \mathcal{D} \to V$ forms a [vector space](../../Algebra/Vector%20Spaces/Vector%20Spaces.md) with $F$, [pointwise addition](./Pointwise%20Addition.md) and [pointwise scalar multiplication](./Pointwise%20Scalar%20Multiplication.md).
>
>>[!NOTATION]
>>
>>This [vector space](../../Algebra/Vector%20Spaces/Vector%20Spaces.md) is usually denoted by $F^{\mathcal{D}}$.
