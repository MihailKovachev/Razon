# Minimum (Sets)

>[!DEFINITION] Definition: Minimum (Sets)
>
>Let $(X, \le)$ be a [partially ordered set](./Partially%20Ordered%20Set.md) and let $S$ be a [subset](../Subsets.md) of $X$.
>
>The **minimum** of $S$ is the smallest element of $S$ (if it exists):
>
>$$m \in S \text{ such that } m \le x \text{ for all } x \in S$$
>
>>[!NOTATION]
>>
>>$$\min S$$
>>
