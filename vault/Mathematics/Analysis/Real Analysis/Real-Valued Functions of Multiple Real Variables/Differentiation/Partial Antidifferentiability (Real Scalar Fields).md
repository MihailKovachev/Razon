# Partial Antidifferentiability (Real Scalar Fields)

>[!DEFINITION] Definition: Partial Antidifferentiability
>
>Let $f: \mathcal{D} \subseteq \mathbb{R}^n \to \mathbb{R}$ be a [real scalar field](../Real-Valued%20Functions%20of%20Multiple%20Real%20Variables.md).
>
>We say that $f$ is **partially antidifferentiable on** an [open set](../../Euclidean%20Space/Euclidean%20Space.md) $U \subseteq \mathcal{D}$ **with respect to the** $k$**-th variable** if there exists a [real scalar field](../Real-Valued%20Functions%20of%20Multiple%20Real%20Variables.md) $F: U \subseteq \mathbb{R}^n \to \mathbb{R}$ whose [partial derivative](./Partial%20Differentiability%20(Real%20Scalar%20Fields).md) w.r.t. the $k$-variable is $f$:
>
>$$\partial_k F = f$$
>
>We call $F$ a **partial antiderivative of** $f$ **with respect to the** $k$**-th variable**.
>
>>[!NOTATION]
>>
>>If the components of the input are labelled $x_1, \dotsc, x_n$, i.e. $f(x_1, \dotsc, x_n)$, then the [set](../../../../Set%20Theory/Sets.md) of all [partial antiderivatives](./Partial%20Antidifferentiability%20(Real%20Scalar%20Fields).md) of $f$ on $U$ w.r.t. the $k$-th variable is denoted as follows:
>>
>>$$\int f(x_1, \dotsc, x_n) \,\mathrm{d}x_k$$
>>
