# Matrix Power Series

## Convergence

>[!THEOREM] Theorem: Convergence via Real Convergence
>
>If the [real power series](../../Real%20Analysis/Real%20Power%20Series.md) $\sum_{k \in \mathcal{I}} a_k (x - c)^k$ has a [convergence radius](../../Real%20Analysis/Real%20Power%20Series.md#Convergence) $R \in \mathbb{R}_{\ge 0} \cup \{+\infty\}$, then the [matrix power series](./Matrix%20Power%20Series.md) $\sum_{k \in \mathcal{I}} a_k (\boldsymbol{X} - c\boldsymbol{I}_n)^k$ [converges](#Convergence) for all [real](../../../Algebra/Matrices/Real%20Matrices/Real%20Matrices.md) [matrices](../../../Algebra/Matrices/Square%20Matrices/Square%20Matrices.md) $\boldsymbol{X} \in \mathbb{R}^{n \times n}$ for which there exists a [matrix norm](../../../Algebra/Matrices/Matrix%20Norms.md) of $\boldsymbol{X} - c\boldsymbol{I}_n$ less than $R$.
