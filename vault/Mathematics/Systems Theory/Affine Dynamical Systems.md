# Affine Dynamical Systems

>[!DEFINITION] Definition: Affine Dynamical System
>
>A [dynamical system](./Dynamical%20Systems.md) $(\mathbb{T}, \mathbb{W}, \mathfrak{B})$ is **affine** if $\mathbb{W}$ is a [vector space](../Algebra/Vector%20Spaces/Vector%20Spaces.md) and $\mathfrak{B}$ is an [affine subspace](../Algebra/Vector%20Spaces/Affine%20Subspaces.md) of the [canonical function space](../Analysis/Functions/Canonical%20Function%20Space.md) $\mathbb{W}^{\mathbb{T}}$.
>
