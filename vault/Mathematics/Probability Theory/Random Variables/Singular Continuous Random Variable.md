# Singular Continuous Random Variable

>[!DEFINITION] Definition: Singular Continuous Random Variable
>
>Let $(\Omega, \mathcal{F}, \Pr)$ be a [probability space](../Probability%20Space.md).
>
>A [random variable](./Real%20Random%20Variable.md) $X: \Omega \to \mathbb{R}$ is **singular continuous** if its [cumulative distribution function](./Cumulative%20Distribution%20Function.md) is [continuous](../../Analysis/Real%20Analysis/Real%20Functions/Continuity%20(Real%20Functions).md) everywhere, and its [probability distribution](./Probability%20Distribution.md) is [singular](../../Measure%20Theory/Singularity%20(Measures).md) with respect to the [Lebesgue measure](../../Measure%20Theory/Lebesgue%20Measure.md) on the [real number line](../../Analysis/Real%20Analysis/Real%20Number%20Line.md).
>
