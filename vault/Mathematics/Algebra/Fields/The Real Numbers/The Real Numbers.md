>[!DEFINITION] Definition: Absolute Value
>
>The **absolute value** is a [function](../../../Analysis/Real%20Analysis/Real%20Functions/Real%20Functions.md) $|\cdot|: \mathbb{R} \to \mathbb{R}_{\ge 0}$ defined for each [real number](./The%20Real%20Numbers.md) $x \in \mathbb{R}$ as
>
>$$
>|x| \overset{\text{def}}{=} \left\{\begin{array}{cc} x &\text{if } x \ge 0 \\ -x &\text{if } x \lt 0\end{array}\right.
>$$
>

>[!THEOREM] Theorem: Triangle Inequality
>
>The [absolute value](./The%20Real%20Numbers.md) has the following properties for all $a, b \in \mathbb{R}$:
>
>$$
>\begin{aligned}
>&|a + b| \le |a| + |b| \\
>&|a - b| \le |a| + |b|
>\end{aligned}
>$$
