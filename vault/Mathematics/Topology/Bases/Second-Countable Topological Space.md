# Second-Countable Topological Space

>[!DEFINITION] Definition: Second-Countable Topological Space
>
>A [topological space](../Topological%20Spaces/Topological%20Space.md) is **second-countable** if it has a [countable](../../Set%20Theory/Cardinality.md) [base](./Base.md) for it.
