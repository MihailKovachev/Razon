# Hash Functions

>[!DEFINITION] Definition: Hash Function
>
>A **hash function** is an [efficient](TODO) [algorithm](TODO) which [computes](TODO) a [function](../../../Mathematics/Analysis/Functions/Functions.md) $h: \mathcal{M} \to \mathcal{H}$ from a [countable](../../../Mathematics/Set%20Theory/Cardinality.md) [set](../../../Mathematics/Set%20Theory/Sets.md) $\mathcal{M}$ to a [finite](../../../Mathematics/Set%20Theory/Cardinality.md) [set](../../../Mathematics/Set%20Theory/Sets.md) $\mathcal{H}$.
>
>We call $\mathcal{M}$ the **input space** or **message space** and $\mathcal{H}$ the **output space** or **hash space**. Given a **message** $m \in \mathcal{M}$, we call $h(m)$ the **hash** of $m$.
>
