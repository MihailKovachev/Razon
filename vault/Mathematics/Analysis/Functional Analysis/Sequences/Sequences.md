# Sequences

>[!DEFINITION] Definition: Sequence
>
>Let $X$ be a [set](../../../Set%20Theory/Sets.md).
>
>A **sequence** of elements of $X$ is a [function](../../Functions/Functions.md) $f: \mathcal{I} \to X$ whose [domain](../../Functions/Functions.md) is an [interval](../../../Set%20Theory/Orderings/Interval.md) $\mathcal{I}$ of [integers](TODO) with a [lower bound](../../../Set%20Theory/Orderings/Boundedness%20(Sets).md).
>
>>[!NOTATION]
>>
>> Instead of writing $f: \mathcal{I} \to X$, we usually  write $(x_n)_{n \in \mathcal{I}}$. Given a specific $i \in \mathcal{I}$, we write $x_i$ instead of $f(i)$.
>>
>
>>[!DEFINITION] Definition: Finite Sequence
>>
>>A [sequence](./Sequences.md) is **finite** if its [domain](../../Functions/Functions.md) is [finite](../../../Set%20Theory/Cardinality.md).
>>
>
>>[!DEFINITION] Definition: Infinite Sequence
>>
>>A [sequence](./Sequences.md) is **infinite** if its [domain](../../Functions/Functions.md) is [infinite](../../../Set%20Theory/Cardinality.md).
>>
>
