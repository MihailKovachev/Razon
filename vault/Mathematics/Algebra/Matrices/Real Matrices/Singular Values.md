# Singular Values

## Singular Value Decomposition

>[!THEOREM] Theorem: Singular Value Decomposition
>
>Every [real matrix](./Real%20Matrices.md) $A \in \mathbb{R}^{m \times n}$ can be represented as the [product](../Matrix%20Product.md) of a [diagonal matrix](../Square%20Matrices/Diagonal%20Matrices.md) $\Sigma \in \mathbb{R}^{m \times n}$ with two [orthogonal matrices](./Orthogonal%20Matrices.md) $U \in \mathbb{R}^{m \times m}$ and $V \in \mathbb{R}^{n\times n}$ as follows:
>
>$$A = U \Sigma V^{\mathsf{T}}$$
>
>Moreover, the entries on $\Sigma$'s diagonal are $A$'s (not necessarily distinct) [singular values](./Singular%20Values.md).
