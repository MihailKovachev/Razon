# Real Distribution

>[!DEFINITION] Definition: Real Distribution
>
>A **real distribution** is a [linear](../Functional%20Analysis/Linearity/Linearity%20(Functions).md) [real-valued function](../Real%20Analysis/Real-Valued%20Functions.md) $T: \mathbb{R}^S \to \mathbb{R}$, whose [domain](../Functions/Functions.md) $\mathbb{R}^S$ is a [set](../../Set%20Theory/Sets.md) of [real functions](../Real%20Analysis/Real%20Functions/Real%20Functions.md) defined on the same [domain](../Functions/Functions.md) $S \subseteq \mathbb{R}$.
>
>>[!NOTATION]
>>
>>Given $\phi \in \mathbb{R}^S$, we write $\langle T, \phi \rangle$ instead of $T(\phi)$.
>>
>
