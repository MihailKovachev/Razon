# Principal Argument (Complex Numbers)

>[!DEFINITION] Definition: Principal Argument
>
>The **principal argument** of a [complex number](./Complex%20Numbers.md) $z \in \mathbb{C}_{\ne 0}$ is defined using the [real arctangent function](../../../Analysis/Real%20Analysis/Real%20Functions/Real%20Trigonometric%20Functions/Real%20Arctangent%20Function.md) as follows:
>
>$$\operatorname{Arg} (z) \overset{\text{def}}{=} \begin{cases} \displaystyle \arctan \frac{\Im (z)}{\Re (z)}, & \Re(z) \gt 0 \\ \displaystyle \arctan \frac{\Im (z)}{\Re (z)} + \uppi, & \Re(z) \lt 0 \text{ and } \Im (z) \ge 0 \\ \displaystyle \arctan \frac{\Im (z)}{\Re (z)} - \uppi, & \Re(z) \lt 0 \text{ and } \Im (z) \lt 0 \\ \displaystyle \frac{\uppi}{2}, & \Re(z) = 0 \text{ and } \Im(z) \gt 0 \\ \displaystyle -\frac{\uppi}{2}, & \Re(z) = 0 \text{ and } \Im (z) \lt 0\end{cases}$$
>
